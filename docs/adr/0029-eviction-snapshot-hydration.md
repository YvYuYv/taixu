# 驱逐前框架侧快照 local 键空间，重挂载时预注水

ADR-0019 的 LRU 驱逐是 dispose，应用状态全丢，用户切回看到冷启动白屏 + 表单丢失。决策：驱逐时由**框架**（非应用）对 `local:{appId}:` 键空间做序列化快照存 sessionStorage（超 2MB 放弃快照），重新挂载时若存在快照则在 `plugin()` 前预注水（hydrate）到 state 服务——"暖启动"。备选"给应用 1s 宽限期自行持久化"被否：应用已挂起、timer 冻结，宽限期回调不可靠（ADR-0027 的盲区）。**新约束**：local 键空间的值必须 JSON 可序列化，否则驱逐时丢弃——写入 CONTEXT.md 使用条款。
