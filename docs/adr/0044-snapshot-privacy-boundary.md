# 暖启动快照键加前缀 + local 键空间禁存敏感数据

ADR-0029 的快照存 sessionStorage——同 tab 同源全部应用共享，应用 A 的快照（可能含表单数据）对应用 B 可读。决策：(a) 快照键加前缀 `__tx_snapshot:{appId}`（防误读，不防恶意读取）；(b) 使用条款声明 `local:` 键空间**禁止存 token/密码/PII**（这类数据存内存态，不进键空间）——与安全基线 §4.4"token 不进广播消息、不进 DevTools 明文"一致。备选"快照加密"被否：同源威胁模型下恶意脚本能读内存里的密钥，是伪安全；真正边界是"sessionStorage 不存敏感数据"。
