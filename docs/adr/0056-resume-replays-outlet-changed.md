# 恢复后 router 重放本槽位 outlet/changed 事件同步路由

挂起应用被恢复时，目标路由可能与挂起时不同（用户从 `/app-a/page1` 切走、从 `/app-a/page2` 切回）。决策：恢复后 router 对该槽位**重放一次 `outlet/changed:{outlet}` 事件**（载荷是当前匹配结果），应用像响应正常导航一样同步到新路由——不为恢复发明第二套路由同步机制。隔离视图本就订阅本槽位事件（ADR-0036/0047），重放自然到达。备选"恢复事件带路由参数、应用自行同步"被否：让应用区分"正常导航"与"恢复导航"两条路径；备选"回滚到挂起时路由"被否：违背用户导航意图。
