# 权限规则只允许本地可判定，远程策略预编译为本地规则下发

`ctx.security.check` 在 scopedFetch 高频路径上同步调用——若权限规则支持远程策略（如"仅工作日可用"需查服务端），每次 fetch 都远程裁决不可接受，且网络分区时所有 fetch 卡死。决策：权限规则**只允许本地可判定**——应用身份、API 模式（glob）、时间窗口（本地时钟）、环境标记；远程策略由管理后台**预编译为本地规则**下发（如把时间窗口展开为具体规则），不在裁决路径上做远程调用。备选"远程策略本地缓存 + TTL"被否：与 ADR-0039"无跨调用缓存"直接冲突，TTL 窗口期是安全漏洞。security 文档须显式声明"权限规则必须本地可判定"。
